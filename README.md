# combOS
### ver2.1.4.4 （このソフトウェアは更新されておらず、いかなるサポートも保証されません。）
HSPコンテスト2019 JBOYSOFT賞受賞作品　[https://hsp.tv/contest2019/cntst_fresult.html#1728](https://hsp.tv/contest2019/cntst_fresult.html#1728)  

## 概要
いわゆるOSもどきです。中学生当時、OSというものに興味を持ち始めてXubuntuとか入れていた頃、同時にHSPをやっていたのでOSの仕組みを模倣してみたくなって作ったものです。コンピュータ部の学園祭でも展示しました。  
2.1.4.4はcombOS ver2系列の最終リリースになります。アップデートサーバーの閉鎖の影響で起動時にエラーが出ますが、それ以外は動作するはずです。(バグで動かない部分があるかもしれませんが、ご容赦ください…)

## 使用技術
- HSP3

## 実行方法
リポジトリごとzipかgit cloneでダウンロードして、BIOS(これを起動してください).exeを開くことで起動できます。
